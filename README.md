# Student Registration Form

A simple and responsive **Student Registration Form** built using **HTML and CSS**.
This project is created as part of my web development practice to improve my understanding of HTML forms and CSS styling.

## 📌 Project Overview

The Student Registration Form allows users to enter basic personal and registration information through a clean and simple form interface.

### Form Includes

* Full Name
* Father's Name
* Mother's Name
* Date of Birth
* Gender
* Other registration details
* Submit button

## 🛠️ Technologies Used

* **HTML5** – Used to create the structure and form elements.
* **CSS3** – Used for styling, layout, spacing, and overall appearance.
